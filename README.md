# দুর্গা সমিতি — এক ফাইলের ওয়েবসাইট

## চালানো
- `index.html` ফাইলটি ব্রাউজারে খুলুন, অথবা GitHub Pages repository-র root-এ এই ফাইলটি রাখুন।
- GitHub Pages-এর জন্য ফাইলের নাম অবশ্যই ছোট হাতের `index.html` রাখুন।

## ডেমো লগইন
অ্যাডমিন: আকাশ কর্মকার / ID `DUR@900` / পাসওয়ার্ড `password`
সেটিংস পাসওয়ার্ড: `AK@2026#`
সদস্য: সায়ন কোলে / ID `DUR002` / পাসওয়ার্ড `Durga@1002`
অন্য সদস্য: সস্তিক কর্মকার / `DUR003` / `Durga@1003`; হমাংস মালিক / `DUR004` / `Durga@1004`; অরিত্র মালিক / `DUR005` / `Durga@1005`

## এক ফাইলের মধ্যে কী আছে
সব পেজের HTML, CSS ও JavaScript `index.html`-এর মধ্যে আছে। লগইন, ড্যাশবোর্ড, সদস্য তালিকা/প্রোফাইল, চ্যাট, গ্যালারি, বিল, রিপোর্ট, অ্যাডমিন সেটিংস এবং JSON ব্যাকআপ একই ফাইলের মধ্যে দেখানো হয়।

## লগইন ত্রুটি
- নাম বা ID ডেটায় না থাকলে `no find any data`
- নাম ও ID মিলে কিন্তু পাসওয়ার্ড ভুল হলে `password is wrong`

## ডেটা ও নিরাপত্তা
ডেটা Local Storage-এ সংরক্ষিত হয়। এটি শুধুমাত্র ওই ব্রাউজার/ডিভাইসের ডেমো; অন্য সদস্যদের সঙ্গে লাইভ শেয়ার হয় না। HTML/JavaScript-এ থাকা ডেমো পাসওয়ার্ড নিরাপদ নয়। প্রকৃত ব্যবহারে Supabase Auth/সার্ভার-সাইড অথেনটিকেশন, ডেটাবেস ও RLS দরকার।
